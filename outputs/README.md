# Это пошаговая инструкция по запуску программы

Судя по тому что Вы это читаете, Вы сейчас находитесь в папке **outputs**. Для начала нашей работы сделайте следующее:

### Шаг 1

Нажмите правой кнопкой мыши в этой папке и выберите пункт **"Открыть в терминале"**. В появившемся черном окне вставьте следующие команды:

```text
cd ..
```

Так мы поменяли директорию на родительскую папку. Дальше нам нужно создать **виртуальное окружение**, но перед этим нам нужно проверить ПК на наличие языка Python.

---

### Немного о Python:

**Python** - это высокоуровневый язык программирования общего назначения. Без него смы не сможем создать окружение да и вообще запустить программу.

Для проверки откроем **cmd**. Зажмите клавиши `Win` + `R`. В поле ввода пишите `cmd`, нажмите "ОК". Готово, вы открыли еще один терминал. Теперь проверим Python. Для этого вставьте команду:

```text
python --version
```

Если вывелось что то типо **Python 3.12...**, значит он установлен. Если нет - установим сами. Для этого вставьте команду:

```text
winget install Python.Python.3.12
```

Готово, Python установлен! Можете закрыть этот терминал и возвращятся в предыдущее окно терминала.

---

### Шаг 2

Создаем окружение о котором говорили ранее. Для этого вставьте комманду:

```text
python -m venv .venv
```

И сразу активируем его командой:

```text
.venv\Scripts\activate.bat
```

Окружение готово. Можем загрузить в него библиоткеи, необходимые для работы программы. Для этого вставьте:

```text
pip install -r outputs/requirements.txt
```

Все готово к запуску. Переходим к шагу 3

---

### Шаг 3

Перейдем в нужную директорию этой командой:

```text
cd src
```

Теперь со спокойной душой можем запустить программу. Для этого введите команду:

```text
python main.py
```

Ох, как же скоротечно она сработала. Результат можете глянуть в папке **outputs**.
